# Software, APIs, standards, and security advisories

| Source | Use it for | How to search |
| --- | --- | --- |
| Official project documentation and repository | Supported behavior, examples, version changes, and source code | Search the project name, exact API or error, and version. Check the version selector and read release notes or tagged source. |
| [RFC Editor](https://www.rfc-editor.org/search/) | Internet protocol specifications | Search by RFC number or protocol. Follow updates, obsoleting RFCs, and errata. |
| [GitHub Advisory Database](https://github.com/advisories) | Dependency advisories, affected versions, and fixes | Search by CVE or package name and ecosystem. Confirm the patched range with the maintainer advisory. |

Treat issue comments as leads. Check release, platform, and configuration before applying a workaround.
