Pick the reference that matches the question. Call `load_skill` with
`id: research-sources` and the relevant `resource`. Start with one file and
load another only if the question needs it.

Search the listed site directly or use `search_web` with a domain filter.
Open the specific page or record before citing it. Check the date, version,
and jurisdiction when they affect the answer. For topics outside the table,
look for the institution that publishes the original record, then use a
specialist index or independent coverage to fill gaps.
