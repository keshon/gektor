Prepare a saved workflow, without executing it. Read workflow_schema before choosing fields or operations. Save only through workflow_save, then validate the saved file with workflow_validate and the required input values. Inspection and preview tools may check source compatibility; they do not establish that a workflow ran.

Prefer version 1 for fixed arguments, version 2 for reusable typed inputs and references to earlier outputs. References are JSON objects: "paths":[{"$input":"source"}], never strings or interpolated paths. Paths are workspace-relative. Use separate output directories and preserve originals. For record steps, read workflow_schema with record_kind; only the operator can register schemas. Report unsupported metadata as a blocker. Do not invent operations, run steps directly, seek shell workarounds, or claim outputs were written. If inputs needed for validation are unknown, save the definition and report what remains unvalidated; the draft cannot pass verification yet.
