# Native document readers

The fixture contains a small DOCX brief, an XLSX sheet and a text PDF.
The expected values are Cedar Works, INVOICE-73, 1847, the saved formula result
3694, and ORBIT-52. These are synthetic files with no external data.

`33-documents-read` checks discovery and use of all three native readers.
It forbids file edits, archive extraction and command execution. The final
answer must contain the values actually read.

`34-documents-workflow` checks the same readers as recipe nodes. It requires
schema discovery, validation, execution and run inspection. The saved recipe
must name all three readers; the answer must contain the fixture values.

Go tests cover exact parsing, paging, output limits, malformed input, permissions
and worker failure. These probes check model decisions. A dry run validates
probe definitions; it does not establish that a model passes.

`39-documents-continuation` uses deterministic generated documents, each with
one item larger than the 32 KiB reader budget. Required evidence lies in the
second DOCX table cell, the XLSX formula after its long stored value, and the
end of a PDF page. The initial item page says `more: false` while the item has
`next_text_offset`. A pass requires successful nonzero `text_offset` reads for
all three formats, each returning the relevant marker, and correct final facts.
The task does not disclose expected markers or prescribe continuation arguments.
Commands, archive operations, edits and delegation are forbidden in this probe.

The generated bytes enter the normal input fingerprint. Go tests prove that
fixtures are deterministic, their initial pages cannot reveal the evidence,
and continuation returns it through schema-valid results without source changes.
One live pass is calibration; repeated passes measure variance. This small probe
does not force context compaction or establish whole-document retention.

The continuation probe allows 900 seconds to accommodate local inference.
Required evidence and trace checks are independent of model speed; a timeout
still fails the run. It does not relax the continuation or forbidden-operation checks.
