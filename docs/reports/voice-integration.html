Voice is connected to Tars chat

Whisper.cpp recognition → configurable external thinking model → resident Chatterbox Nano or Turbo. Text remains available when speech is disabled or playback fails.

Run

From D:\Projects\dev\keshon\tars, with the thinking server running at the profile's endpoint (default http://127.0.0.1:8080):

agent.exe -profile profiles\chat-veyra-voice.json -chat -tui -voice
  1. Voice → Play character greeting checks output and warms the speech model without microphone or thinking requests.
  2. F8 or Ctrl+R starts recording. Wait for “Recording” before speaking.
  3. F8 finishes. The complete recording is transcribed and submitted as a visible user turn.
  4. Esc cancels recording, recognition, generation or playback. Completed text remains available.

Voice → Speech settings changes the microphone, Nano/Turbo, model directory and recording cap. After applying these settings, enable Voice again. Regular prompt and generation edits keep the speech worker warm.
