Settings belong to the conversation

Actual TUI renderer fixtures, with illustrative model names. Shared square borders, category rail, focus colors and fixed actions replace the giant configuration form. Apply preserves the current session, committed turns and draft.

F6 focuses categories; arrows navigate. Tab moves through controls. Enter opens searchable choices. F4 reveals Advanced fields. Ctrl+S applies staged changes across categories; Esc cancels them. Esc inside a picker returns to its parent.

Model discovery runs asynchronously; canceled and stale scans cannot change the active form. Ctrl+B opens a folder browser; Ctrl+R scans/refreshes; Ctrl+L exposes an optional folder path. External servers can provide model names; manual entry remains available if discovery is unsupported.

Local tests cover category staging, cancellation, history/archive preservation, save-failure rollback, model search and browsing, late results and authenticated server discovery. Character, microphone and profile pickers plus applied-voice sample playback are now connected. See the next iteration.
