Commander styling

Panel titles now have a connected separator underneath. Status indicators are plain text. Session → Compact conversation works in both modes; Chat keeps the opening exchange and eight recent turns, backing up the original archive.

One continuous menu band. The spacing before each hotkey uses its key background. Focus highlights only the SESSIONS / CHAT / AGENT title; panel bodies stay neutral. Menus, command pickers and dialogs share one blue-gray palette, full-row selection and rounded corners. Tab changes panel focus.

These are colored snapshots from the actual TUI renderer, not a separate mockup.
