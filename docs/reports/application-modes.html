One terminal entry

.\\agent.exe -tui

First launch: Chat, voice off. Subsequent bare launches remember the effective profile, mode, workspace and voice choice in var/application.json. Explicit CLI combinations remain temporary overrides.

Session → Conversation mode / voice selects Chat/Agent, a profile, a workspace and Off/Push-to-talk/Hands-free. Enter opens choices; Profile and Workspace use the shared browser. Agent initially opens in Plan and retains existing permission gates. Nothing executes merely by switching.

Runner transitions preserve the source archive and carry dialogue context and the draft into an idle session. Chat receives prior tool output as text and offers no tools. The original Agent archive retains full tool records.

Speech works with either runner. Chat streams spoken sentence chunks. Agent voices final answers and keeps intermediate tool output in the transcript. Agent Speech settings can select microphone and Chatterbox variant.
