Practical Commander menu flows

Actual TUI renderer fixtures, 100 × 28. Settings open editable forms directly. Apply starts a new conversation while preserving the old archive and draft. Cancel keeps the active conversation untouched. Coding connection panels are explicitly read-only.

Available now: character and user, prompts, generation/context, model connection, save as profile, effective-prompt preview, direct rename and confirmed delete. Voice controls now include push-to-talk, greeting playback, speech settings and service details. Voice integration and test results.
