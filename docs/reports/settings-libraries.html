One picker language across settings

Actual renderer fixtures with illustrative file locations. Character cards, microphones and profiles use the same searchable controls as thinking models.

Enter opens a choice, arrows select and Esc goes back. File choices support Ctrl+B browsing, Ctrl+L location entry, Ctrl+D drives and Ctrl+R refresh. Card/profile details load asynchronously; invalid character cards cannot be selected.

Profiles load as staged configuration. Apply retains the current session and its history. Ctrl+D in the Profiles workspace saves a new portable copy; existing profiles are never overwritten.

Speech → Ctrl+P plays/stops the applied built-in Chatterbox voice. Apply a changed variant first. Closing settings cancels playback. Nano and Turbo each expose one built-in reference voice in the current adapter; no custom-reference voice library is claimed.

FFmpeg enumeration on this machine found Storm Pro and ARDOR without opening capture. Automated checks cover nested card browsing, invalid cards, staged profile loading, portable save/overwrite protection and late preview results. Audio sample playback uses the existing tested service; physical speaker acceptance remains a live user check.
