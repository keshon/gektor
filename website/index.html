A coding agent and workflow runner for the terminal.

GEKTOR is a terminal app for working on code with an AI agent and running saved workflows. Connect a local model server, an API, or an eligible ChatGPT account.

Windows and Linux. Open source under the MIT license.

Two ways to work

Agent

Describe a task and let the model choose the tools. Use Plan mode to inspect the project, then switch to Act for edits and commands.

Saved sessions let you pick up the conversation later.

Tools and automation

  • Tools loaded on demand

    Optional toolsets are discovered and enabled as needed. Unused tool definitions stay out of the model context.

  • Native file and media tools

    Read DOCX, XLSX, and PDF files, process images, and work with archives using built-in operations shared by Agent and Workflows.

  • Reusable JSON recipes

    Define inputs, dependencies, conditions, and iteration in a workspace file. Recipes can call other recipes and return named outputs.

  • Explicit model steps

    Add model-generation steps where needed. Workflows without model steps run without an agent session or model connection.

  • Review, then continue

    Pause before a selected operation and inspect its inputs. Approval continues the saved run without repeating completed steps.

  • Schedules and webhooks

    Submit recipes through cron schedules, an HTTP API, or authenticated webhooks. A running workflow service executes the queued jobs.

Get started

  1. Download and extract a release

    Choose the build for your operating system. Release binaries do not need Go installed.

  2. Launch Agent

    Open a terminal in the extracted folder and run:

    .\start-gektor-agent.cmd
    ./gektor -tui

  3. Connect a model and choose your project

    Open Settings → Model connection. Use llama.cpp, KoboldCPP, an OpenAI-compatible API, or an eligible ChatGPT account. Local models need a separately running server and tool-call support.

    Choose your folder under GEKTOR → Change workspace.
